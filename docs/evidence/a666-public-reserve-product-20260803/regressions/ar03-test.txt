AR-03 regression evidence: quorum-first commit with offline validator converges after recovery

Contract (recovery spec section 6.1, AR-03): quorum-first commit does not
require an intentionally offline validator, while later propagation converges
after recovery.

Design note (Troll-authorized deviation from the path doc's three-validator
suggestion): production BFT quorum is `(2n / 3) + 1`
(crates/ordering_fast/src/lib.rs:336), so three registered validators require
3-of-3 and cannot tolerate any offline validator. The test therefore uses the
smallest production-valid topology: four registered ACTIVE validators, quorum
3, with validator-3 active but intentionally offline/non-voting for the first
commit. The test asserts this arithmetic explicitly so threshold drift fails
the test.

Canonical input vector: chain_id "postfiat-local", validator ids
validator-0..3, offline validator-3, block-one transfer amount 41, block-two
transfer amount 42, view 0, transparent batches. Validator keys are generated
by `init` per run; the state-machine flow is deterministic and all
cross-validator equality assertions hold for any generated key set.

What the test proves
--------------------
1. Block 1 certificate: 4 registered validators, quorum 3, exactly 3 votes,
   no vote from validator-3; source commits block 1 with that certificate.
   (Fails if the commit waits on validator-3.)
2. Propagation/recovery: validator-1, validator-2, and the recovered
   validator-3 each apply block 1 through the real authenticated certified
   path (archived batch payload + external certificate reconstructed from the
   archived block + canonical replay block record, staged exactly like
   rpc_catch_up_preflight_blocks at crates/node/src/rpc_cli.rs:4386).
3. Block 2 certificate: 4-of-4 votes, including validator-3 voting from its
   own restored directory; committed and propagated the same way.
4. Terminal convergence: all four validator directories report identical
   (height=2, tip, state root) and verify_blocks passes on each.
   (Fails if catch-up is skipped.)
