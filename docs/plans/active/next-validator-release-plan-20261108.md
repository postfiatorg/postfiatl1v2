Done on main in the commit "Append account history index rows in chunked shards per commit instead of rewriting whole files", and it ships with this release. Index schema v3 keeps each account's rows in chunk files of at most 64 rows plus a small head, and `account_tx_index_meta.json` and `account_tx_index.json` hold counts and ranges only; a commit rewrites only the last chunk and head of each touched account and the two metadata files (`crates/node/src/account_tx_disk_index.rs`; [runbook](../../runbooks/account-tx-index.md#layout)). Owner: this lane. Operator-cache format change, no consensus change.
