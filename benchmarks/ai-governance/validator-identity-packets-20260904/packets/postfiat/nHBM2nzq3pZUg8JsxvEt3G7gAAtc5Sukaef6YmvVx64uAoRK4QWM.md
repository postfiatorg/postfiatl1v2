## Activities

JollyDinger publicly presents a collection of tools for the Post Fiat testnet: a wallet manager, XRPL-based decentralized-exchange interface, NFT explorer, validator setup wizard, and a “Bull or Bear” data application. ([JollyDinger homepage](https://www.jollydinger.com/); [Jolly DEX](https://www.jollydinger.com/jollydex.html); [PFT Wallet](https://www.jollydinger.com/pftwallet.html))

The Bull or Bear application solicits market-sentiment answers from participants, rewards them with tokens, and states that the resulting dataset is supplied to AGTI for model training. Its stated stakeholders include beta participants and the Post Fiat ecosystem. ([Bull or Bear one-pager](https://www.jollydinger.com/bullorbear-one-pager.html))

The associated GitHub account publishes six repositories, including a Post Fiat network dashboard and open-source validator setup and monitoring software aimed at prospective validator operators. ([GitHub profile](https://github.com/jollydinger); [PFT Validator Suite](https://github.com/jollydinger/pftvalidatorsuite); [Post Fiat dashboard](https://github.com/jollydinger/pft-dashboard))
