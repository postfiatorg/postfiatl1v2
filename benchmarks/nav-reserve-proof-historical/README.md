# Historical reserve-proof fixtures

This directory contains the minimal historical witness corpus required by the
open reserve-proof kit's deterministic regression tests. The files were moved
from the retired `docs/evidence/` tree; keeping them under `benchmarks/` makes a
clean clone testable without treating operational evidence as active docs.
They are test inputs only, not current reserve attestations.
